# Авто-Орієнтир Харків (Auto-Orientir)

Інструмент для агентств нерухомості м. Харкова для миттєвого визначення точних адресних даних, адміністративного району, житлового комплексу (ЖК), класу новобудови, поштового індексу, найближчого метро та релевантних орієнтирів.

## Можливості для рієлторів

- **Повна база Єдиного адресного реєстру м. Харкова**:
  - **2 953 вулиці** (включно з усіма активними вулицями та вулицями зі статусом «Зі змінами», багаторівневою історією перейменувань та офіційними аліасами).
  - **78 818 активних будинків** із точними координатами, корпусами (`корп.`), офіційним адміністративним районом та поштовим індексом (`61xxx`).
- **Розумний двомовний пошук (УКР + РУС + старі назви)**:
  - Пошук працює за новими й старими назвами українською та російською мовами (наприклад: `Гагарина` → `Аерокосмічний просп.`, `Героев Труда` → `Нескорених вул.`, `Пушкинская` → `Григорія Сковороди вул.`, `Целиноградская` → `Мирослава Мисли вул.`).
- **Швидкий розбір повного рядка адреси**:
  - Вставте рядок з оголошення чи месенджера (наприклад: `пр. Гагарина 174 корп 3 кв 45`) — система автоматично виділить вулицю, корпус, квартиру та заповнить картку.
- **Двостороння прив'язка ЖК (293 комплекси та котеджні містечка)**:
  - Автоматичне визначення ЖК та класу за адресою будинку, або вибір ЖК зі списку з миттєвим переходом до його будинків/корпусів.
- **Очищені рієлторські орієнтири та метро**:
  - Автоматичний баланс: мікрорайон/місцевість + знакові ТРЦ, парки або ринки поруч. Інтерактивні чіпси дозволяють додавати або прибирати сусідні орієнтири та станції метро в один клік.
- **Інтерактивна карта (OSM + Супутник Esri)**:
  - Клік у будь-яку точку карти або перетягування маркера автоматично знаходить найближчий будинок у реєстрі (зворотний геокодинг за кілька мілісекунд).

## Структура проєкту

```text
auto-orientir/
├── index.html               # Інтерфейс форми об'єкта нерухомості
├── style.css                # Стилі форми, чіпсів та автокомпліту
├── script.js                # Пошуковий рушій, геокодинг, логіка ЖК та карти
├── data/
│   ├── streets.json         # Вулиці Харкова з історією перейменувань та аліасами
│   ├── houses.json          # Координати будинків, корпуси, райони та індекси
│   ├── complexes.json       # База ЖК та котеджних містечок Харкова
│   ├── districts.json       # Полігони адміністративних районів
│   ├── metro.json           # 30 станцій метро з лініями та старими назвами
│   └── landmarks.json       # Курована база орієнтирів Харкова
└── scripts/
    └── sync_register.py     # Скрипт оновлення вулиць і будинків із геопорталу ХМР
```

## Запуск локально

Відкрийте проєкт через будь-який локальний HTTP-сервер (необхідно для завантаження JSON через `fetch`):

```bash
python -m http.server 8000
```

Після цього відкрийте у браузері `http://localhost:8000`.

## Оновлення бази з Єдиного адресного реєстру м. Харкова

Щоб синхронізувати актуальні перейменування вулиць та нові адреси напряму з офіційного реєстру (`geo-portal.khmr.gov.ua`):

```bash
python scripts/sync_register.py
```
