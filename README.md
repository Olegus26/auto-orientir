# Авто-Орієнтир Харків (Auto-Orientir)

Інструмент для агентств нерухомості м. Харкова для миттєвого визначення точних адресних даних, адміністративного району, житлового комплексу (ЖК), класу новобудови, поштового індексу, найближчого метро та релевантних орієнтирів.

## Можливості для рієлторів

- **Повна база Єдиного адресного реєстру м. Харкова**:
  - **2 953 вулиці** (включно з усіма активними вулицями та вулицями зі статусом «Зі змінами», багаторівневою історією перейменувань та офіційними аліасами).
  - **78 818 активних будинків** із точними координатами, корпусами (`корп.`), офіційним адміністративним районом та поштовим індексом (`61xxx`).
- **Розумний двомовний та нечіткий пошук (УКР + РУС + старі назви + друкарські помилки)**:
  - Пошук у полі «Улица» працює за новими й старими назвами українською та російською мовами, з урахуванням акання та одруківок (наприклад: `холоднаярская` → `Холодноярська вул. (колиш. Брянський)`, `корча` → `Амосова вул. (колиш. Корчагінців)`, `Гагарина` → `Аерокосмічний просп.`).
  - Підтримується вставка повного рядка адреси просто в поле вулиці (наприклад: `пр. Гагарина 174 корп 3 кв 45`).
- **Повна двостороння база ЖК м. Харкова за каталогом Rieltor.ua + ЛУН (190 комплексів із 100% заповненим класом)**:
  - Сформована рівно за алфавітним покажчиком новобудов Харкова на Rieltor.ua (`A-Z`, `А`…`Я`) та збагачена повними даними з ЛУН (`адреси усіх секцій/корпусів`, `клас`, `забудовник`, `синоніми`, `координати`).
  - **188 із 190 ЖК прямо прив'язані до 408 офіційних будинків/корпусів** з Єдиного адресного реєстру м. Харкова (строго за введеними адресами зі статусу будівництва ЛУН), а **118 ЖК** мають народні назви й синоніми (`ЖК Білий слон` → `ЖК Дім у Сокільниках`, `Дача 55` / `Пори року` → `ЖК Времена года`, `Янтарний` → `ЖК Бурштиновий` тощо).
  - Автоматичне визначення ЖК та класу за адресою будинку, або розумний нечіткий пошук ЖК за комерційною назвою, народною назвою, забудовником (`Житлобуд-1`, `ЖС-2`, `Авантаж`), старою чи новою вулицею (навіть з одруківками на кшталт `жк по улици велозовожскаая`).
- **Автоматичне визначення Адмін. району, Масиву за реальними кордонами (полігонами), Метро (у радіусі 1.8 км) та Орієнтирів**:
  - **Масиви та мікрорайони з реальними кордонами (`data/massifs.json`)**: **141 житловий масив і мікрорайон** за каталогом Rieltor.ua (`0-9`, `А`…`Я`) із замкнутими полігонами кордонів (OpenStreetMap + Rieltor.ua + квартальні межі, 0 фіктивних кіл), обчисленими площами, офіційними адмін. районами та двомовними синонімами (`Піски (522 м.р.)`, `627 м.р.` / `624-А`, `521 м.р.` / `608`, `Північний-1 (Джерела)`…`5`, `Павлове поле`, `Шатилівка`, `Нагірний`, `Поділ`, `ХТЗ`, `Обрій`, `Рогань` тощо). Точка будинку перевіряється за **point-in-polygon** входженням у кордон масиву (або відстанню до межі), а контур активного масиву підсвічується на карті.
  - **Метро в радіусі 1.8 км**: автоматично підставляє найближчу станцію метро лише тоді, коли вона дійсно знаходиться в межах пішої/місцевої досяжності (`≤ 1.8 км`). Якщо в радіусі 1.8 км метро немає (наприклад, Велозавод / 627 м.р., Рогань, 759-А м.р., Сокільники, Залютине), поле автоматично отримує значення `Нет` із підказкою та опціональним чіпсом найближчої станції.
  - **Орієнтири (`data/landmarks.json`)**: **215 конкретних об'єктів** без жодного дублювання масивів і синонімів (75 об'єктів Rieltor.ua + куровані парки, ТРЦ, ринки, виші, лікарні, супермаркети Клас/РОСТ/Восторг). Пріоритезує різноманітні типи поруч із будинком та підтримує клік по чіпсах.
- **Векторна карта у стилі Rieltor.ua / ЛУН (MapLibre GL JS)**:
  - Фірмова векторна палітра (золотисто-жовта мережа магістралей, пастельно-зелені парки та ліси, чисті українські підписи без рекламного шуму, номери будинків на крупному масштабі).
  - **Інвертована підсвітка району (Spotlight Mask) + контур масиву**: при виборі адмін. району все за його межами м'яко притінюється індиговою вуаллю, а контур вибраного масиву чітко окреслений пунктирною фіолетовою межею.
  - **30 станцій метро Харкова у кольорах ліній**: іконки з фірмовою літерою **М** для ключових станцій на оглядовому масштабі та розкриття всіх 30 станцій при наведенні або наближенні; клік по станції підставляє метро у форму.
  - **Фіолетові точки ЖК та будинків + гібридний режим «Супутник»**: інтерактивні точки корпусів ЖК (з тултіпом і автозаповненням по кліку) та перемикач `Карта / Супутник`.
  - Клік у будь-яку точку карти або перетягування маркера миттєво знаходить найближчий будинок у реєстрі (зворотний геокодинг).

## Структура проєкту

```text
auto-orientir/
├── index.html               # Інтерфейс форми об'єкта нерухомості
├── style.css                # Стилі форми, чіпсів та автокомпліту
├── script.js                # Пошуковий рушій, геокодинг, логіка ЖК та карти
├── data/
│   ├── streets.json         # Вулиці Харкова з історією перейменувань та аліасами
│   ├── houses.json          # Координати будинків, корпуси, райони та індекси
│   ├── complexes.json       # База ЖК та котеджних містечок Харкова
│   ├── districts.json       # Полігони адміністративних районів
│   ├── massifs.json         # 141 житловий масив і мікрорайон із полігонами кордонів (OSM + Rieltor.ua)
│   ├── metro.json           # 30 станцій метро з лініями та старими назвами
│   └── landmarks.json       # Курована база 215 орієнтирів Харкова (парки, ТРЦ, ринки, виші, лікарні)
└── scripts/
    ├── sync_register.py     # Скрипт оновлення вулиць і будинків із геопорталу ХМР
    ├── sync_complexes.py    # Скрипт повного збору, прив'язки корпусів та оновлення бази ЖК
    └── sync_massifs.py      # Скрипт генерації масивів із кордонами (OSM/Rieltor.ua) та дедуплікації орієнтирів
```

## Запуск локально

Відкрийте проєкт через будь-який локальний HTTP-сервер (необхідно для завантаження JSON через `fetch`):

```bash
python -m http.server 8000
```

Після цього відкрийте у браузері `http://localhost:8000`.

## Оновлення баз даних

Щоб синхронізувати актуальні перейменування вулиць та нові адреси напряму з офіційного реєстру (`geo-portal.khmr.gov.ua`):

```bash
python scripts/sync_register.py
```

Щоб оновити локальну базу всіх ЖК Харкова (`data/complexes.json`) із відкритих каталогів та реєстру будинків:

```bash
python scripts/sync_complexes.py --refresh
```
